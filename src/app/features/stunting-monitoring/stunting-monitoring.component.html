1. Struktur Multi-Sheet dalam Satu File

Seluruh lembar kerja program intervensi (contoh: anak, gizi, BUMIL, remaja) dapat berada dalam 1 berkas workbook .xlsx yang sama.

2. Kolom Kunci Identitas Wilayah (Join Key)

Setiap sheet harus memiliki satu kolom identitas wilayah (contoh: Puskesmas, Kecamatan, atau Kabupaten/Kota). Normalisasi otomatis akan membersihkan kode wilayah (misal: 3301 - KAB. CILACAP) agar join akurat.

3. Header Bertingkat & Penentuan Baris

Mendukung template dengan cell merge vertikal/horizontal. Anda dapat mengatur Baris Header Awal, Header Akhir, dan Mulai Data secara fleksibel untuk setiap sheet agar nama kolom terbaca utuh.

4. Filter Otomatis Baris Akumulasi (Exclude)

Baris ringkasan seperti TOTAL, JUMLAH, serta baris kosong/catatan otomatis dinonaktifkan dari penjumlahan (agregasi SUM) untuk menghindari penghitungan ganda (double count).
