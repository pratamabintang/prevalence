# Evaluasi Kinerja Pemantauan Stunting Tingkat Kabupaten/Kota

Modul pemantauan stunting diperluas untuk mendukung evaluasi kinerja komparatif 35 Kabupaten/Kota secara mandiri melalui metode murni `StuntingEvaluationEngine.evaluateRegionalScorecards(...)`. Keputusan ini menetapkan bahwa target tahun berjalan berlaku seragam sementara baseline tahun sebelumnya dihitung riil per baris wilayah, disajikan dalam antarmuka terintegrasi berupa Matriks Komparasi Antar-Wilayah dual-mode (semua indikator triwulan aktif vs semua triwulan satu indikator) dan slide-out drawer Kartu Rapor Wilayah, serta diekspor ke sheet khusus "Komparasi Kab-Kota" pada laporan buku kerja Excel. Pendekatan ini dipilih dibandingkan filter tunggal (dropdown) atau kalkulasi ad-hoc di komponen agar supervisor Dinkes dapat segera memetakan kesenjangan capaian antarwilayah secara obyektif tanpa mengorbankan isolasi logika dan performa reaktif sistem.
